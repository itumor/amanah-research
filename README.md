# Project AMANAH — أمانة

## An Experiment in Islamic Ethical AI

**Independent research concept · v0.1 · 25 November 2026**

> Can autonomous AI agents consistently follow an ethical framework grounded in the Qur’an and authentic Sunnah when doing so comes at a cost?

## The idea

Imagine giving an AI agent a simulated human life: a career, family commitments, financial resources, ambitions, relationships, memory and the ability to make decisions. Instead of optimizing only for task completion or financial gain, the agent operates under a documented ethical constitution derived from Islamic sources and intended for review by qualified scholars.

What happens when telling the truth threatens its promotion? When an attractive opportunity conflicts with its ethical commitments? When justice requires acting against its own simulated interests?

AMANAH proposes studying these questions through controlled, longitudinal simulations. It is not a religious chatbot, a fatwa engine or an attempt to create a conscious or believing machine. The project examines observable computational behavior.

## Why AMANAH?

Amanah (أمانة) conveys trust and responsibility. The Qur’an connects the return of trusts with just judgment ([4:58](https://quran.com/4/58)). These values motivate the project's emphasis on accountable decision-making.

## Research approach

- Define a source-grounded ethical framework with explicit uncertainty and scholarly review.
- Create fictional agents with identical starting conditions and realistic life events.
- Compare agents with different explicit ethical instructions using the same model and equivalent resources.
- Record proposed and executed actions, evidence, interventions and simulated consequences.
- Evaluate consistency, integrity, practical outcomes and failures without equating measured compliance with faith.

The research draws on [Constitutional AI](https://arxiv.org/abs/2212.08073), [Generative Agents](https://arxiv.org/abs/2304.03442), and existing [Islamic AI ethics research](https://doi.org/10.1007/s13347-023-00668-x). AMANAH's proposed synthesis is a longitudinal behavioral experiment, not a claim of academic priority.
